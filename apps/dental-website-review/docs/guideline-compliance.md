# OpenAI plugin guideline compliance

Every section of OpenAI's [plugin guidelines](https://developers.openai.com/plugins/plugin-guidelines),
the [remote MCP review requirements](https://developers.openai.com/plugins/deploy/app-review) and the
[submission page](https://developers.openai.com/plugins/deploy/submission), read on 2026-11-09, with
how Dental Website Review meets it and what proves it. Automated checks live in
`tests/guidelines.test.ts` (run with `pnpm test`) and `scripts/check-listing.mjs` (run with
`pnpm check:listing` against the live site and server). Re-read the guideline pages before each
submission; they change. Markdown versions are served by appending `.md` to each page URL.

Status: **automated** (a test or the listing script fails if it regresses), **manual** (checked by
hand on the date given), **n/a** (the section does not apply, with the reason).

## Before each submission

1. `pnpm test` and `pnpm lint` pass.
2. Deploy the server, then `pnpm check:listing` passes (version, pages, challenge, tools).
3. Run the five positive and three negative prompts in ChatGPT and compare against
   `expected_behavior` word for word; answers to narrow prompts must not include contact details
   or staff names. Re-record the walkthrough if behaviour changed.
4. `pnpm package:plugin`, upload the ZIP, scan tools, resolve findings, submit.
